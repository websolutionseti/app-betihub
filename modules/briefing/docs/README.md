# BetiHub - Plataforma de Consultoria Digital

## 📋 Sobre o Projeto

BetiHub é uma plataforma completa de consultoria digital que oferece ferramentas avançadas para coleta de informações, análise de dados e geração de relatórios personalizados para empresas.

## 🎯 Módulo de Briefing

### Visão Geral

O módulo de briefing é o coração da plataforma BetiHub, projetado para otimizar o processo de consultoria através de uma abordagem estruturada e visual.

### 🔧 Funcionalidades Principais

#### 1. Módulo de Coleta de Informações (Passo a Passo)
- Interface intuitiva com questionários dinâmicos
- Fluxo guiado por etapas
- Validação em tempo real
- Salvamento automático de progresso
- Personalização por tipo de negócio

#### 2. Módulo de Banco de Dados e Permissões (Prisma + SQL)
- Estrutura de dados otimizada
- Sistema de permissões granular
- Auditoria completa de ações
- Backup automático
- Relatórios de uso

#### 3. Módulo de Geração Visual e Relatórios
- Templates personalizáveis
- Gráficos interativos
- Exportação em múltiplos formatos (PDF, Excel, PowerPoint)
- Dashboards em tempo real
- Comparativos históricos

#### 4. Fluxo Visual do Processo de Consultoria
- Diagramas Mermaid interativos
- Visualização do pipeline completo
- Tracking de progresso
- Notificações automáticas

#### 5. Diagramas UML, MER e DER
- Modelagem visual da arquitetura
- Documentação técnica automatizada
- Versionamento de esquemas
- Validação de integridade

### 🎨 Design System

A plataforma utiliza um design system moderno e profissional:

- **Cores Primárias**: Azul profissional (#4F9CF9)
- **Cores Secundárias**: Verde sucesso (#34D399)
- **Tipografia**: System fonts para melhor performance
- **Componentes**: Shadcn/ui customizados
- **Responsividade**: Mobile-first approach

### 🚀 Tecnologias

- **Frontend**: React + TypeScript + Tailwind CSS
- **Backend**: Node.js + Prisma ORM
- **Banco de Dados**: PostgreSQL
- **Autenticação**: JWT + Role-based access
- **Deploy**: Vercel/Railway

### 📊 Fluxo de Uso

1. **Cadastro do Cliente**: Informações básicas e segmentação
2. **Questionário Dinâmico**: Coleta estruturada de dados
3. **Análise Automática**: Processamento inteligente das informações
4. **Geração de Relatório**: Documento personalizado com insights
5. **Apresentação**: Interface para apresentação dos resultados

### 🎯 Benefícios

- ⚡ **Eficiência**: Redução de 70% no tempo de coleta de informações
- 🎨 **Profissionalismo**: Relatórios visuais de alta qualidade
- 📈 **Escalabilidade**: Suporte a múltiplos clientes simultaneamente
- 🔒 **Segurança**: Dados protegidos com criptografia end-to-end
- 📱 **Mobilidade**: Acesso completo via dispositivos móveis

### 🛠️ Como Usar

1. Clone o repositório
2. Instale as dependências: `npm install`
3. Configure as variáveis de ambiente
4. Execute as migrações: `npx prisma migrate`
5. Inicie o servidor: `npm run dev`
